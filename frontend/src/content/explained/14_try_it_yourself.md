# Try It in Three Steps

Test the full system in three easy steps:

### Step 1: Start a Run
Go to the **Grid** tab and click **Start Baseline Session**. Watch the 14-junction grid run at normal 60 Hz.

### Step 2: Launch the Demo
Go to the **Scenarios** tab and click **Run Primary Demo**. Watch the system inject a lie on Bus 4 and spot the trouble.

### Step 3: View the Incident
Open the case in the **Incidents** tab. Read the summary, check the clues, test the impact, and verify the fix.
