# Reading an Incident Page

When trouble stays active, GridShield opens an incident case.

### What Is on the Screen

- **In Plain Words:** A short three-sentence summary of the event.
- **Cause and Domain:** Names the problem and whether it is cyber or physical.
- **Certainty:** Shows how sure the system is about the cause.
- **Evidence List:** Shows exact clues with numbers and meter names.
- **Timeline:** A clean list of events in exact order.
- **Verification:** Proof that the chosen fix restored safe power.
