# Questions and Answers

### Is this a real power grid?
No. It is a software model for learning and research.

### Could this attack a real grid?
No. The code only changes local numbers in memory. It has no hacking tools.

### Why does it say "Unknown"?
If clues are not clear, it marks the state unknown rather than guessing.

### Where do scores come from?
All scores come from test data and match the saved metrics file.
