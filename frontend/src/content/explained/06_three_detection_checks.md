# How GridShield Spots Trouble

GridShield checks all data with three layers of defense:

### 1. The Physics Math Check
Uses classical math to test if numbers obey power laws. It catches bad data fast.

### 2. The Odd Pattern Spotter
An AI model trained on quiet normal days. It flags odd shapes in data.

### 3. The Problem Classifier
An AI model trained on past attack runs. It names the exact type of trouble.

### When GridShield Is Not Sure
If models disagree, the system marks the result `Unknown` instead of guessing.
