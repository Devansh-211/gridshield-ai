# Limitations and Safety

GridShield is built with strict safety boundaries.

### Core Rules

1. **No Outside Network:** The code runs in memory only. It cannot send real network commands.
2. **Not for Real Grids:** It must never connect to physical power plants.
3. **Public Safe:** Web visitors have isolated sessions. Secret keys never leave the server.
4. **Short Requests:** All runs execute in short time-capped steps.
