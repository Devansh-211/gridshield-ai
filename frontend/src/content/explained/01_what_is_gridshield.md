# What is GridShield AI?

GridShield is a software digital twin. It is built for learning and research. It models a simulated 14-junction electrical grid. It helps people study cyber attacks and defenses safely.

> [!IMPORTANT]
> GridShield is a simulation for learning. It does not connect to real power lines. It cannot control real equipment.

### The Six-Step Loop

When trouble happens, GridShield runs six steps:

1. **Notice:** Fast checks inspect readings every second.
2. **Find the Cause:** Tests tell if trouble is a broken wire or an attack.
3. **Explain:** An AI writer makes a plain note citing clear clues.
4. **Test What Happens:** The tool tests what happens if no one acts.
5. **Pick a Fix:** The system suggests a safe fix.
6. **Check It:** A 3-way test proves the fix made the grid safe.
