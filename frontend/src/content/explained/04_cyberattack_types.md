# What an Attack Looks Like

GridShield simulates five kinds of trouble in software memory.

### Five Simulated Events

1. **False Data Injection:** A sensor report is changed to lie. The control room gets fooled and raises generator output too high.
2. **Rogue Command:** An unauthorized signal forces a generator to cut power.
3. **Replay:** Old data from yesterday is repeated to hide a real problem today.
4. **Denial of Service:** Sensor data stops coming, causing a blind spot.
5. **Physical Line Trip:** A wire breaks. Electricity naturally shifts to other lines.

All attacks run in software memory only. No real packets are sent.
