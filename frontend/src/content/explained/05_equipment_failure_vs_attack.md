# Broken Parts vs Attacks

When alarms ring, operators must ask a key question: *Is a part broken, or is a sensor lying?*

### Three Big Clues

1. **Do Neighbors Agree?** When a real wire breaks, neighbor sensors see power shift. If only one sensor screams while its neighbors stay calm, that single sensor is suspect.
2. **Does Physics Make Sense?** If no physical power flow can make those readings, data was altered.
3. **Did a Command Fire?** Did a controller move on its own without user consent?
