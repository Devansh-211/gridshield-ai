# Testing a Fix

Before applying a fix, the tool checks if the remedy will work.

### The 3-Way Test

GridShield tests three states:

1. **Before (Baseline):** Calm grid state before the trouble started.
2. **During (No Fix):** What happens if the problem keeps going.
3. **After (With Fix):** The state after taking safe action.

The tool checks voltages and line loads. It marks the fix verified when all wires return to safe bounds.
