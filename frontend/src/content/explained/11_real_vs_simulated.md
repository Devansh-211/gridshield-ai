# Real vs Simulated

Honesty is a core rule in GridShield. Here is what is real and what is simulated:

- **The Grid:** Simulated in software using a standard 14-bus test grid.
- **Sensors:** Simulated readings with normal random noise.
- **Attacks:** Simulated in code memory. No outside packets are sent.
- **AI Models:** Real trained machine learning code.
- **Math Checks:** Real statistical tests running live.
- **Database:** Real database tables storing state.
